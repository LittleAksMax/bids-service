# Bids Service

## Reporting API

We use the `v3` of the [Amazon Reporting API](https://advertising.amazon.com/API/docs/en-us/guides/reporting/v3/overview)
to generate each user's metrics. Naturally, aligning with the project's boundaries, we will use the _Sponsored Product_ report type.
We can view all the report types at [this link](https://advertising.amazon.com/API/docs/en-us/guides/reporting/v3/report-types/overview).
